## ✨ Features

- 🌓 **Dynamic Theme Switcher:** Smooth transition between cyberpunk Dark Mode and crisp Slate Light Mode with persistent user preferences stored in `localStorage`.
- 📱 **Fully Responsive Layout:** Optimized across mobile, tablet, laptop, and ultra-wide desktop displays using modern CSS Grid and Flexbox.
- 🚀 **Featured Projects Showcase:** Live links, GitHub repositories, and interactive demo previews for full-stack and AI applications.
- 🛠️ **Categorized Skills Matrix:** Interactive filters covering Programming Languages, Web Technologies, Databases, ML & AI, and Cloud/DevOps tools.
- 📜 **Verified Credentials:** Showcase of 20+ professional certifications from Wipro, Adobe, SAP, Microsoft, AWS, Oracle, and freeCodeCamp with direct verification links.
- 📬 **Dual-Channel Contact Form:** Seamless message delivery powered by EmailJS API with automated instant mailto fallback to guarantee zero lost inquiries.

## 💻 Local Setup & Development

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SHYAMESH-KOMATLA/Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Launch the website:**
   - Double-click `index.html` to open directly in any browser, or
   - Use VS Code extension **Live Server** (`Go Live`) for live reloading at `http://localhost:5500`.
